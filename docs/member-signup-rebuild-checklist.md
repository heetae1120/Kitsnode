- `shopping-bid` 작업트리 `ea8a8cb` 및 미커밋 `OVERVIEW.md`에는 확장 초대 후보, 실계정 발송·수동 수락, 광고 성과 조회, 모의 스케줄 및 제한적 입찰 변경 시험이 기록되어 있다. 수정된 파일을 덮어쓰지 않는다.
- 성과 API와 네이버 화면을 실제 계정으로 비교한 기록은 있으나 당시 API principal이 운영 조회 권한이라고 확인되지는 않았다. 운영 조회 재시험은 광고주 책임자 로그인 대기 기록이 있다.
- 실제 자동입찰은 기록상 중단되어 있고 모의 스케줄러와 구분한다. 네이버 일반 변경 및 If-Match 시험은 충돌을 차단하지 못했다.
- 탈퇴는 운영 시험 경로와 연결 계정을 차단하는 별도 후보가 공존한다. 사용자의 최신 방향은 연결 회원도 본인이 탈퇴하고 해당 연결 정보를 정리하는 것이다.
- `kitsnode_edit`는 어드민 미리보기이고 실제 방문자 화면은 별도 프론트 저장소다. 두 저장소의 편집 계약과 기존 미커밋 변경을 보존한다.
