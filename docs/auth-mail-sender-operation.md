# 인증 메일 발신자 운영 기록

확인일: 2026-11-16

- 키츠노드와 인트라넷은 현재 동일한 Supabase Auth 프로젝트와 사용자 지정 SMTP를 공유한다.
- 운영 SMTP의 발신자 표시 이름을 `키츠 인트라넷`에서 `키츠노드`로 변경했다. 이는 저장소 코드 변경이 아닌 외부 운영 설정이며, 두 서비스의 인증 메일에 공통 적용된다.
- 키츠노드의 비밀번호 재설정 시험 요청 후 사용자가 메일 수신과 `키츠노드` 발신자 표시를 확인했다. 인트라넷 경로의 별도 실수신 시험은 수행하지 않았다.
- 발송 한도는 당시 확인 기준 공유 프로젝트 시간당 30통, 동일 사용자 재요청 간격 60초다. 메일 제공자의 별도 제한과 전달률은 추가 확인이 필요하다.
- 향후 서비스별 발신자 이름 분리는 별도 프로젝트 또는 공유 Auth 전체 메일을 처리하는 훅과 발송 공급자 연결이 필요하다. 운영 적용 전 가입·재설정·초대·이메일 변경 등 양쪽 경로와 장애 복구를 시험해야 한다.
- 키츠노드 프론트 로그인 진입점 및 인증 화면 개선은 운영 `main`의 `2712a9d`와 `deb7322`에서 배포됐다. 이 기록 자체는 해당 코드를 `develop`으로 이식하거나 브랜치를 병합하지 않는다.
