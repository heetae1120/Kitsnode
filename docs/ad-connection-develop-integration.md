# 광고계정 연결 코드의 develop 반영

이 브랜치는 광고계정 연결 화면, 네이버 초대 확장프로그램 0.3.1 후보, 회원 로그인 및 동의·연결 서버의 필요한 코드를 포함한다. 코드 반영만으로 원격 Supabase 설정을 변경하거나 함수를 배포하지 않는다.

- 기능은 `NEXT_PUBLIC_*` 설정으로 제어하며, 설정이 없으면 꺼진다. 테스트 확장프로그램의 ID·동의 증명 서버 허용 ID는 별도 운영 설정이며 일치해야 한다. 증명 함수 소스의 기본 허용 대상은 게시된 확장프로그램 ID다. 개발자 모드 시험본을 기본 운영 대상으로 취급하지 않는다.
- 회원 동의의 초기 세 마이그레이션과 초대 동의·회원 탈퇴 마이그레이션은 기존 운영 DB의 마이그레이션 이력에 기록된 버전과 SQL을 사용했다. 해당 이력의 적용 여부를 확인하기 전에는 다른 이름으로 동일 SQL을 재실행하지 않는다.
- 탈퇴 마이그레이션은 공유 직원·스토어 테이블을 전제로 한다. 이 저장소만으로 빈 DB를 재구축할 수 있다고 가정하지 말고, 공유 프로젝트의 스키마와 기존 마이그레이션 이력을 먼저 대조한다.
- `tests/sql/run-invite-execution-real-stack.sh`는 로컬의 일회용 컨테이너에서 합성 계정으로 동의·증명 경로를 테스트한다. 운영 초대 발송이나 네이버의 실제 권한 부여는 검증하지 않는다.
