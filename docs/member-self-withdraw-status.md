# 키츠노드 본인 회원 탈퇴 작업 상태

2026-11-20. 회원 탈퇴는 시험 계정으로 검증하는 단계이며 일반 회원에게는 활성화하지 않았다. 운영 회원의 탈퇴는 실행하지 않았다.

- 운영 Supabase에 탈퇴 진행 계정의 직접 접근 제한, 광고 연결 정리 및 직원 인증 참조 정리 함수가 적용됐다. 탈퇴 함수는 서비스 역할만 실행할 수 있으며, 마이그레이션 직후 차단된 회원은 0명이었다.
- 인트라넷 v197에는 별도 서버 비밀로 보호되는 직원 신원 정리 경로가 배포됐다. 공개 요청은 거부되며, 유효한 비밀을 가진 잘못된 요청도 거부됨을 확인했다. 공용 Gmail이나 회사 소유 업무 데이터는 변경하지 않는다.
- 독립 Cloudflare 원장에 본인 삭제 의도와 미완료 재시도 커서를 지원하는 Worker와 2분 주기 재시도가 배포됐다. Supabase 탈퇴 Edge Function은 서버 비밀과 본인 확인을 사용하며 일반 회원은 서버의 시험 계정 허용 목록 때문에 아직 탈퇴할 수 없다. 실제 삭제 요청 기록은 아직 없다.
- 합성 회원을 사용하는 로컬 Supabase Auth/PostgREST에서 이메일 삭제 후 기존 비밀번호 로그인 실패, 같은 이메일로 새 ID 재가입, 기존 토큰의 격리 데이터 접근 차단, 동의/광고/직원 참조 정리를 확인했다. 합성 `custom:naver` identity 삭제·재연결과 인트라넷 SQLite 스키마 호환성도 시험했으나, 실제 네이버 OAuth 로그인·탈퇴·재가입 검증은 아니다.
- 남은 단계: 사용자가 지정한 전용 네이버 시험 계정을 서버 시험 허용 목록에 지정하고 키츠노드 UI에서 실제 탈퇴·재가입·데이터 정리를 검증한다. 네이버 OAuth는 신규 Auth 계정을 자동 생성할 수 있으므로 가입 동의 전에는 로그인을 완료하지 않도록 별도 진입 경로를 검증한다. 전체 검증 후 서버의 일반 회원 허용 설정을 바꾼다.
