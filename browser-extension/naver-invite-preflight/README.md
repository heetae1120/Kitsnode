# 광고계정 자동 확인 확장프로그램 후보

Chrome 웹 스토어 게시 버전 0.1.0을 기준으로 계정 확인 전용 메시지(`kitsnode.account.start.v1`, `kitsnode.account.get.v1`)를 추가한 0.3.0 후보입니다. 지정된 키츠노드 화면에서만 시작하고, 확장프로그램이 연 네이버 탭의 선택된 광고계정 URL에서 ID를 읽습니다. 이 단계에서 초대나 동의는 실행하지 않습니다. 기존 사전 동의 실행은 별도의 서버 승인 절차를 사용합니다.

운영 웹의 자동 연동은 0.3.0 게시 및 실제 검증 전까지 꺼져 있습니다. 동의 검증 서버는 활성화되어 있습니다. 실제 네이버 정책 원문과 계정, 세션, 동의 및 권한을 확인한 뒤에만 초대를 시도합니다. 시험 전용 계정 없이 초대 발송으로 검증하지 마세요.
