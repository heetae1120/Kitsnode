# 광고계정 자동 확인 확장프로그램 후보

Chrome 웹 스토어 게시 버전 0.1.0을 기준으로 계정 확인 전용 메시지(`kitsnode.account.start.v1`, `kitsnode.account.get.v1`)를 추가한 0.2.0 후보입니다. 지정된 키츠노드 화면에서만 시작하고, 확장프로그램이 연 네이버 탭의 선택된 광고계정 URL에서 ID를 읽습니다. 이 단계에서 초대나 동의는 실행하지 않습니다. 기존 사전 동의 실행은 별도의 서버 승인 절차를 사용합니다.

운영에 적용하려면 웹과 확장프로그램을 함께 배포하고 동의 검증 서버 및 웹 설정을 확인해야 합니다. 현재 운영 동의 검증 함수는 의도적으로 비활성화되어 503을 반환하며, 해당 함수의 확장 ID는 현재 웹 스토어 항목에 맞췄으나 실행 스위치는 닫혀 있습니다. 서버 기능을 켜기 전에 게시된 확장 ID, 네이버 정책 원문, 운영 환경과 실제 광고계정에서의 전체 흐름을 검증해야 합니다. 시험 전용 계정 없이 초대 발송으로 검증하지 마세요.
