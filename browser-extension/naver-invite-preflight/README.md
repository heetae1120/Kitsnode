# 광고계정 자동 확인 확장프로그램 후보

0.3.1 시험 후보입니다. 지정된 키츠노드 화면에서 시작하고, 확장프로그램이 연 네이버 탭의 선택된 광고계정 URL에서 ID를 읽습니다. 동의 후 동일 계정과 탭이 유효하면 다시 선택하지 않고 초대 과정으로 이어집니다. 계정 확인 단계 자체에서는 초대나 동의를 실행하지 않으며, 초대 실행에는 별도의 서버 승인 절차가 필요합니다.

운영 웹의 자동 연동은 호환 버전 게시 및 실제 검증 전까지 꺼져 있습니다. 동의 검증 서버는 활성화되어 있습니다. 실제 네이버 정책 원문과 계정, 세션, 동의 및 권한을 확인한 뒤에만 초대를 시도합니다. 시험 전용 계정 없이 초대 발송으로 검증하지 마세요.
