키츠노드 광고 계정 연결

광고주가 네이버애즈에서 kitsnode를 운영 조회 권한으로 초대합니다.

  1. 네이버애즈에서 광고주 계정으로 직접 로그인하고 연결할 광고 계정을 선택하세요.
  2. 권한 관리의 권한 받은 회원 화면을 열고 아래 자동 진행을 시작하세요.
  3. 네이버에 표시되는 개인정보 제공 및 회원 초대 정책을 직접 확인하고 동의하세요.

초대가 발송됐는지 네이버의 초대 중인 회원에서 확인해 주세요. 키츠노드의 초대 수락과 연결 확인은 별도 단계입니다.

로그인 후 광고 계정의 권한 관리 화면에서 시작해 주세요.

직접 진행하거나 상태 확인하기

자동 진행을 사용할 수 없다면 각 단계를 직접 진행할 수 있습니다. 네이버의 정책 동의는 직접 해주세요.

발송 결과가 불확실하면 다시 보내기 전에 네이버에서 초대 상태를 확인해 주세요.
