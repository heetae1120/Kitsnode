# 네이버 검색광고 API 확인 요청 초안

안녕하세요. 쇼핑검색 상품 광고의 광고그룹 입찰가를 외부 서비스에서 조정하는 기능을 검토 중입니다. 다음 사항에 대한 공식 명세 또는 지원 여부를 확인 부탁드립니다.

1. `PUT /ncc/adgroups/{adgroupId}?fields=bidAmt` 요청에 기존 입찰가, 리소스 버전, ETag 등을 조건으로 지정하여, 광고주센터 또는 다른 API 요청이 먼저 수정했다면 **서버가 원자적으로 변경을 거부**하도록 할 수 있나요? 가능하다면 요청·응답 예시와 충돌 시 상태 코드를 알려 주세요. 조회 후 일반 수정 요청을 보내는 방식은 조회와 수정 사이의 동시 변경을 막을 수 없습니다.
2. `GET /ncc/ads?nccAdgroupId=...`의 최대 반환 건수와 페이징 및 응답 잘림 확인 방법은 무엇인가요? 쇼핑검색 광고그룹에서 활성·중지 소재를 모두 포함한 전체 목록임을 확인할 수 있나요?
3. 쇼핑 상품 마스터 보고서와 실시간 소재 조회는 각각 어떤 상태의 소재를 포함하며, 생성 시점이나 반영 지연 때문에 차이가 생길 수 있나요? 전체 영향 범위를 확정하는 공식적인 방법이 있다면 알려 주세요.

이 내용은 문의 초안이며, 아직 네이버에 전송하지 않았습니다. 계정 ID, API 키, 개인정보는 포함하지 않았습니다.
