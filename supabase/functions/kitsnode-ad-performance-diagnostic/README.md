# 유니킴 검색광고 성과 진단 후보

사용자·운영자 검증을 통과한 운영자만 호출할 수 있는 별도 읽기 진단입니다. 유니킴(2647636)의 서버 검증 계정 매핑에서 검색광고 캠페인 목록을 얻고, 정렬된 첫 캠페인 한 개의 한국 시간 기준 전일을 포함한 최근 7일 성과를 `/stats`로 요청합니다. 캠페인 ID와 API 자격 증명은 반환하지 않으며, 표시되는 성과는 해당 캠페인 하나의 수치이지 계정 전체의 합계가 아닙니다. 연결·권한에 대한 완전한 실서비스 검증이나 성과 API의 완전성을 증명하지 않습니다.

기존 `kitsnode-ad-api`를 변경하지 않습니다. `diagnosticFiles()`로 독립 함수 `kitsnode-ad-performance-diagnostic`를 JWT 검증 활성화 상태로 배포하고, 배포된 진단 페이지를 관리자 세션에서 사용합니다. 테스트 후 동일 함수명에 `diagnosticFiles({disabled:true})`, `disabled.ts`, `verify_jwt:false`를 배포하여 외부 요청이 410을 반환하는지 확인하고, 진단 페이지 플래그를 다시 끄고 배포합니다. 함수 대체는 삭제가 아닙니다.

현재 단계는 격리 모의 네트워크와 Deno·브라우저 검사만 통과한 후보이며 실제 네이버 `/stats` 응답은 확인하지 않았습니다. 실패 시 자동 반복하지 말고 안전한 범위의 원인 코드만 확인합니다.
